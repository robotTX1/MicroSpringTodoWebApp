# Micro Spring Todo Web App

Client for the Micro Spring Todo Service (https://github.com/robotTX1/MicroSpringTodoService)

## Developer guide

Required tools:
- Java 21 (GraalVM - https://www.graalvm.org/downloads/#)
- Docker
- Dockercompose
- Node 22.20.0 (https://nodejs.org/en)
- NPM

## To run this project locally you need to setup `local-config` directory
1. Create `local-config` directory
2. Copy the files from `test-config` to `local-config`
3. Replace dummy values with real ones (DM me)

## Use IDEA formatter config:
1. Intellij IDEA -> Settings -> Code Style -> Scheme
2. Click on the cog icon -> import scheme -> Intellij IDEA code style XML
3. Import the `FormatterConfig` from the `build_config` directory
4. Use this style
